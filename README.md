# HortiFruti PDV — Downloads

Este repositório contém somente arquivos públicos de distribuição do HortiFruti PDV.

- O instalador de cada versão fica em **Releases**.
- `latest.json` é o manifesto consultado pelo aplicativo para verificar atualizações.
- `SHA256SUMS.txt`, anexado a cada release, permite conferir a integridade do instalador.

O código-fonte e os dados de desenvolvimento não são publicados aqui.
Distribuição pública das versões do HortiFruti PDV.
